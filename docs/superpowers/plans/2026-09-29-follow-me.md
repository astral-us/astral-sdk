# Follow-Me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one-tap typed commands and an offline, rear-camera follow mode that acquires one person, maintains a 1.5-metre stand-off without switching to a newly central person, reacquires conservatively, and stops safely.

**Architecture:** Add a pure continuity tracker and a dedicated `FollowMeCoordinator` behind narrow perception, motion, and clock protocols. Feed it frame-coherent `RoverYOLO` detections and AR depth through a live adapter. Route finalized text and speech through a local `OperatorCommandRouter`, while retaining `MissionAgent` for ordinary commands. Project the coordinator state through a focused Talk view model into the existing `ConversationView`.

**Tech stack:** Swift 6, Observation, SwiftUI, XCTest/XCUITest, ARKit scene depth, Vision/Core ML `RoverYOLO`, PhroverKit, `NavigationController`, iOS 26 simulator, and a LiDAR-capable physical iPhone rover.

**Approved design:** `docs/superpowers/specs/2026-09-29-follow-me-design.md`

**Later scope amendment:** `docs/superpowers/specs/2026-09-30-follow-me-voice-only-amendment.md` supersedes the typed-command UI, draft-clearing, and Send-button steps below. Preserve the speech-finalized router, push-to-talk gesture, Stop Following button, and follow safety behavior.

## Global Constraints

- Keep follow recognition, tracking, and control fully on-device.
- Use the rear-camera AR session; do not introduce front-camera capture or camera switching.
- Treat `Detector`/`RoverYOLO` as a person detector, not identity recognition.
- Select image-centre proximity only during initial acquisition. Never switch tracks merely because another person becomes central.
- Preserve the approved defaults: confidence 0.50, observation age 500 ms, 30-degree scan increments, 360-degree initial-search limit, 1.5-metre stand-off, 1.25–1.75-metre hold band, 0.30-metre goal-change threshold, at most three goal updates per second, two-second pose/depth recovery, and ten-second reacquisition.
- Reuse `NavigationController` safety and cancellation; do not issue raw rover-control commands from follow code.
- Exactly one subsystem may own motion. Follow mode and an ordinary `MissionAgent` mission must not run concurrently.
- Keep the existing push-to-talk interaction and route only its finalized transcript.
- SwiftPM iOS minimum: 26.0. Do not add dependencies or front-camera capture, change the existing RoverYOLO model, or weaken `NavigationController` safety checks.
- Keep `RoverYOLO` person detections separate from identity recognition; after occlusion only conservative spatial reacquisition is permitted.
- Do not stage or overwrite unrelated working-tree files: `.serena/project.yml`, `.opencode/`, `AGENTS.md`, or existing `.superpowers` assets.
- A successful return from current `NavigationController.cancel()` **does not** prove the rover stopped: it launches an untracked stop Task. `cancelAndWait()` discards stop errors. Follow motion must use a throwing, acknowledged stop before any new owner or scan/goal begins; failed acknowledgment blocks all further movement.
- Drive, Navigate and Silent Search share the rover. While follow mode owns or reserves movement, block other tabs from initiating movement; refuse follow start while another tab owns it, or await its confirmed release. Leaving Talk/backgrounding immediately inhibits new goals and then awaits a confirmed stop.
- Commands below run from the repository root. `scripts/test-swift-sdk.sh` selects an available iOS 26+ iPhone simulator. For app tests obtain a UDID with `scripts/test-swift-sdk.sh --print-udid` and pass `-destination "id=$UDID"`; do not assume an iPhone 16 Pro simulator is installed.
- Commit checkpoints below apply only when the user explicitly authorizes commits; otherwise leave files unstaged for review.

```swift
@MainActor
private final class SuspendedStopMission: OperatorMission {
    private var requested = false
    private var requestWaiter: CheckedContinuation<Void, Never>?
    private var stopWaiter: CheckedContinuation<Void, Never>?
    func handle(_ text: String) async {}
    func cancelCurrentMissionAndWait() async throws {
        requested = true
        requestWaiter?.resume()
        requestWaiter = nil
        await withCheckedContinuation { stopWaiter = $0 }
    }
    func waitUntilStopRequested() async {
        if requested { return }
        await withCheckedContinuation { requestWaiter = $0 }
    }
    func finishStop() {
        stopWaiter?.resume()
        stopWaiter = nil
    }
}
@MainActor
private final class RecordingFollow: OperatorFollow {
    var state: FollowMeState = .idle
    private(set) var startCount = 0
    func start() async -> Bool { startCount += 1; return true }
    func stop() async -> Bool { state = .stopped; return true }
}
```
